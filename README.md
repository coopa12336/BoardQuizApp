# 早押し・ボードクイズ アプリ

複数人が同じ部屋（ルーム）に入り、タブレットで手書き解答を行うボードクイズ用の
Webアプリです。判定者（正誤判定・進行役）と回答者（複数人）に分かれて使用し、
プロジェクターへ回答を大きく投影できます。Arduinoを使った早押し機とも連携できます。

**インターネット上に公開して、誰でもURLを開くだけで使えるようにできます。**
参加者側は npm や Node.js のインストールは一切不要です（技術的な準備が必要なのは、
最初に一度だけサーバーを公開する作業だけです）。もちろん、これまで通り会場のLAN内
だけで動かすオフライン運用も可能です。

---

## 1. できること

- 判定者が部屋を作成（部屋名・任意パスワード）
- 回答者はタブレットのブラウザから入室し、指で（あるいはタッチペンで）手書き解答
- 判定者画面で全回答者の解答をリアルタイムに一覧表示、正誤を記録
- プロジェクター用の「投影専用画面」で、全員一覧 or 1人を大きく表示
- **Arduinoの早押し機能は完全に任意です。** 持っていない参加者や、会場で接続できない
  参加者がいても、その人はボード解答（手書き）だけで問題なく参加できます。使う場合は、
  投影PCの**ブラウザから直接**接続し、押した順番を自動判定・表示できます
  （サーバー側には特別な設定不要。Chrome/EdgeのWeb Serial APIを使用）
- Arduinoが手元になくても、判定者画面のテストボタンで早押し動作をシミュレート可能
- **正誤判定に応じてスコアを自動集計。** 「押して1着で正解」「押さずに不正解」など
  6パターンの基本ルールを標準搭載し、それぞれの点数（プラス/マイナス）は判定者画面で
  自由に変更可能。3着以降のルールも後から好きなだけ追加できます
- **Excel/CSVで用意した問題・解答一覧を投影画面に表示。** 判定者画面でファイルを
  読み込んでおけば、任意のタイミングで問題文・解答・解説・作問者名を投影画面に
  大きく表示できます（表示時間を決めて自動で消すことも可能）

## 2. 全体構成

```
                 [プロジェクター]
                        │(HDMI等)
                 ┌──────┴──────┐
   Arduino─USB─→│    投影PC     │← Chrome/Edgeでdisplay.htmlを開き、
                 │ (display.html)│  「接続する」ボタンでArduinoに接続
                 └──────┬──────┘
                        │ インターネット 
                        ▼
              ┌───────────────────┐
              │  公開サーバー(1台)   │  ← npm start はここだけで実行
              │ (Render等にデプロイ) │     （常時稼働・URLを発行）
              └───────┬───────────┘
                        │
        ┌───────────────┼───────────────┐
   [判定者PC/タブレット]         [回答者タブレット ×人数分]
   ブラウザでURLを開くだけ         ブラウザでURLを開くだけ
```

サーバーは1箇所（クラウド、または会場PC）で1回だけ起動しておけば、あとは
判定者・回答者・投影PCはすべて「ブラウザでURLを開くだけ」で参加できます。

## 3. 公開URLで運用する場合（推奨・誰でも使える構成）

Render.com の無料〜安価なプランを例に説明します（Railway、Fly.ioなど他の
Node.js対応ホスティングでも同様の手順で動きます）。

1. このフォルダをGitHubリポジトリにアップロードする
   （GitHubアカウントが無ければ https://github.com で無料作成）
2. https://render.com にアクセスし、GitHubアカウントで登録
3. 「New +」→「Web Service」→ 手順1のリポジトリを選択
4. 設定項目
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: 無料枠でも動作確認は可能（後述の注意点あり）
5. 「Create Web Service」でデプロイ開始。数分待つと
   `https://<自分のアプリ名>.onrender.com` のようなURLが発行されます
6. このURLを判定者・回答者・投影PCの全員に共有すれば、それぞれのブラウザで
   開くだけで使えます

> **無料プランの注意点**: しばらくアクセスが無いとサーバーが自動的にスリープし、
> 次のアクセス時に起動し直すまで数十秒かかることがあります。また、状態は
> サーバーのメモリ上にのみ保持されるため、スリープ復帰や再起動が起きると
> 部屋のデータは消えます。大会本番の直前にアクセスして起こしておく、または
> 有料プラン（常時起動）に切り替えることをおすすめします。

## 4. 会場LAN内だけで運用する場合（オフライン運用）

インターネットに繋げない会場では、従来どおりPC1台でサーバーを起動し、
同じWi-Fi/LAN内の端末だけでアクセスする構成も可能です。

```bash
cd quiz-board-app
npm install
npm start
```

起動後、投影PC自身のブラウザでは `http://localhost:3000` へ、他の端末（判定者・
回答者タブレット）は投影PCのIPアドレスを使って `http://<投影PCのIPアドレス>:3000`
へアクセスします（IPアドレスはWindowsなら `ipconfig`、Macなら `ifconfig | grep inet`
で確認できます）。

> 会場のWi-Fiがゲスト分離（クライアント間通信の遮断）をしている場合、端末同士が
> 通信できないことがあります。可能であれば大会専用のモバイルルーターやスイッチ
> ングハブ＋固定回線での構築をおすすめします。

> **Arduinoを使う場合の注意（オフライン運用時）**: Web Serial APIは「セキュアな
> コンテキスト」（`https://` のページ、または `http://localhost`）でしか動作しません。
> 投影PC自身で `http://localhost:3000/...` を開いて接続する分には問題ありませんが、
> 他のPCからIPアドレス経由でdisplay.htmlを開いてもArduino接続ボタンは使えません。
> Arduinoは必ず「投影PC自身」で、かつ`localhost`のURLから接続してください。
> （公開URL運用の場合は `https://` になるため、この制約はありません。）

## 5. 使い方の流れ

1. **判定者**: ホーム画面で「部屋を作る」→ 部屋名・任意パスワードを入力して作成
2. **判定者**: 「判定者として入る」から同じ部屋名で入室 → 判定者画面が開く
3. **回答者**: 各タブレットのホーム画面で「回答者として入る」を選び、部屋名・
   パスワード・自分の名前を入力して入室（Arduino早押し機を使う場合は、割り当てた
   ボタン番号もここで入力）
4. **投影PC**: ホーム画面下部の「プロジェクター表示画面」に部屋名を入力して開く
   （ログイン不要・閲覧専用。Arduinoを使う場合はここから接続する）
5. 判定者画面で「次の問題へ」を押すとボード・早押しがリセットされ、回答受付が始まる
   （回答者全員のロックも自動的に解除されます）
6. 回答者はボードに手書きし、「回答を確定する」で送信
7. 判定者は「回答をロックする（全員）」で受付終了、「全員の解答を公開する」で
   投影画面に表示し、各回答者タイルで実際の状況に合う得点ルールのボタンを押して
   仮選択する（この時点ではまだスコアに反映されません。5e参照）
7a. 全員分を選び終えたら「🎬 正誤判定を確定する（演出あり）」を押す。ここで
   一斉にスコアへ反映され、投影画面で正解/不正解ごとに異なる演出が流れます
8. 回答者タイルの**回答ボード部分（名前の下の白い枠）をクリック**すると、その人の
   解答が投影画面に大きく表示されます。もう一度クリックすると一覧表示に戻ります
   （プロジェクター表示の切り替えは「⚙ その他の設定」の中にもあります）

早押し機能を使う場合は、判定者画面の「早押し結果」に押した順番がランプ盤のように
表示されます。

判定者画面の頻繁に使う操作（進行操作・タイマー・早押し結果・回答者一覧）は常に
表示されていますが、大会中に頻繁には触らない設定項目（プロジェクター表示の切り替え、
早押し演出、Arduinoテスト、得点ルール設定）は「⚙ その他の設定」の中にまとめて
あります。クリックすると展開して編集できます。

### 5a-1. 投影画面（全員一覧表示）のマス目は参加人数に応じて自動調整

投影画面の「全員を一覧表示」モードは、固定サイズのマス目ではなく、**その時点の
参加人数に応じてマス目の数を自動調整**します。人数が少ないほど1人あたりの表示が
大きくなります。

| 人数 | マス目 |
|---|---|
| 1人 | 1人だけを画面いっぱいに表示 |
| 2人 | 横に2人並べて表示 |
| 3人 | 横に3人並べて表示 |
| 4人 | 2×2に並べて表示 |
| 5〜9人 | 3列（行数は人数に応じて自動） |
| 10〜16人 | 4列（行数は人数に応じて自動） |
| それ以上 | 概ね正方形に近くなるよう自動調整 |

途中で参加者が増減した場合も、次に画面が更新されたタイミングで自動的にマス目が
組み直されます。

### 5a. 投影画面への公開（シンキングタイム対策）

回答者がボードに書いている内容は、**判定者画面には常にリアルタイムで表示されます**が、
**投影画面（プロジェクター）には既定では表示されません**（「🙈 非公開」というプレース
ホルダーが表示されます）。シンキングタイム中に他の回答者の解答が観客席から見えて
しまわないようにするための仕様です。

「進行操作」カードの「全員の解答を公開する」／「全員を非公開にする」で一斉に
切り替えられます。特定の人だけを公開/非公開にしたい場合は、各回答者タイルの
「👁 公開する」「🙈 非公開にする」ボタンで個別に切り替えられます。次の問題に
進むと、公開状態は自動的に「全員非公開」に戻ります。

### 5b. 個別ロック解除

「回答をロックする（全員）」を押した後でも、特定の回答者だけ記入を続けさせたい
場合は、その人のタイルにある「🔓 ロック解除」ボタンで個別に解除できます
（もう一度押すと「🔒 ロックする」に変わり、再度ロックできます）。タイルの名前欄には
現在の状態が 🔒（ロック中）/ ✏️（記入可能）のアイコンで表示されます。

### 5c. 制限時間タイマー

「制限時間タイマー」カードで秒数を入力して「タイマー開始」を押すと、判定者画面・
回答者画面・投影画面それぞれにカウントダウンが表示されます。時間になると
**自動的に全員の回答がロックされます**（「回答をロックする（全員）」を押すのと
同じ動作です）。判定者が「タイマー停止」を押すと、自動ロックせずに途中で
タイマーだけを止められます。

### 5d. 正誤判定の「仮選択」と「確定」演出

各回答者タイルの得点ルールボタンは、押した瞬間にはスコアへ反映されません。
選んだボタンが青く光り「仮選択中」の状態になるだけです（タイル名前欄にも
「●選択中」と表示されます）。想定している使い方は以下の流れです。

1. 回答者全員のボードを見ながら、それぞれの得点ルールボタンを仮選択していく
   （やり直したい場合は同じボタンをもう一度押すと仮選択を取り消せます。
   別のボタンを選び直すこともできます）
2. 全員分を選び終えたら、「正誤判定の確定」カードの
   「🎬 正誤判定を確定する（演出あり）」を押す
3. その瞬間、仮選択されていた分が一斉にスコアへ反映され、**投影画面でも
   正解者は緑、不正解者は赤の演出（点数の表示つき）が同時に流れます**

まだ仮選択していない回答者がいても確定ボタンは押せます（その人は今回は
スコアが変動しないだけで、次の問題やあとからの確定で改めて選べます）。
次の問題に進むと、仮選択状態はリセットされます。

### 5e. 正解/不正解によらない手動の加減点

各回答者タイルの一番下にある「±点数」欄に数値（マイナスも可）を入力して
「加減点する」を押すと、得点ルールとは別に、その場でスコアを自由に加減できます。
こちらは即時反映で、確定ボタンを待たずにスコアに加算されます。ボーナス点や、
得点ルールで表現しきれない独自の採点をしたい場合にお使いください。

## 6. 問題文・解答の投影（問題ファイルの読み込み）

事前に用意した問題・解答一覧のファイルを判定者画面に読み込ませておき、任意の
タイミングで投影画面に大きく表示できます。ボード解答・早押しの進行とは独立した
機能なので、好きなタイミングで使えます（例: 判定が終わった後に正解と解説を
まとめて見せる、など）。

### 6.1 対応しているファイル形式

「問題ファイルの読み込み・投影」カードから、以下のようなファイルを読み込めます。

- Excel（`.xlsx` / `.xls`）
- CSV（`.csv`）
- その他、スプレッドシートの書き出し形式（`.ods` など）

1行目を見出し行として扱い、次のような列を認識します（順番は自由、多少の
表記ゆれも自動で吸収します）。

| 内容 | 認識される見出しの例 |
|---|---|
| 問題番号 | `No` / `番号` / `問題番号` |
| 問題文 | `問題` / `問題文` / `Question` |
| 解答 | `解答` / `答え` / `正解` / `Answer` |
| 解説・コメント | `解説` / `コメント` / `Comment` |
| 作問者 | `作問者` / `出題者` / `Author` |

問題番号の列が無い場合は、上から数えた順番が自動でNo.として使われます。
Googleスプレッドシートをお使いの場合は「ファイル→ダウンロード→カンマ区切り値
(.csv)」で書き出したものをそのまま読み込めます。

### 6.2 使い方

1. 「問題ファイルの読み込み・投影」カードでファイルを選択し「読み込む」を押す
2. 「← 前の問題」「次の問題 →」、または位置を直接指定してブラウズできます
   （ここでの操作は判定者の画面だけに表示され、投影画面にはまだ反映されません）
3. 表示中の問題文・解答・解説・作問者を確認し、必要なら「投影画面での表示時間」
   に秒数を入力（空欄なら手動で消すまで表示され続けます）
4. 「📤 SEND（投影画面に表示）」を押すと、その内容が投影画面いっぱいに表示されます
5. 指定した秒数が経過すると自動的に消えます。すぐに消したい場合は
   「投影画面から消す」を押してください

投影画面に表示されている間は、ボードの一覧・拡大表示よりも問題パネルが手前に
表示されます。消えると元のボード表示に戻ります。

## 7. 得点ルールの設定（スコア自動集計）

各回答者タイルには、正解/不正解の2択ボタンではなく、**設定されている得点ルール
（最低6パターン、追加すればそれ以上）がそのままボタンとして並びます**。
判定者はその問題での実際の状況に最も近いボタンを選んで押すだけです。

各ボタンには、実際に使う早押しボタンをイメージしたアイコン（黒い台座＋赤いドームに
○/×を重ねたもの）と、押さずに解答した場合は鉛筆に○/×を重ねたアイコンが表示され、
どの状況を選んでいるか一目でわかるようになっています。また、その回答者が実際に
押していた着順に対応するボタンには青い破線の枠がついて「おすすめ」を示しますが、
判定者は必要に応じてどのボタンでも自由に選べます（実際にクリックしたボタンには
金色の枠がつき、その問題でどのルールを適用したかが記録されます）。

標準で用意されている6パターン（すべて判定者画面の「⚙ その他の設定」内の
「得点ルール設定」カードで点数を自由に変更できます）:

| 条件 | 初期値 |
|---|---|
| 押して正解（1着） | +10点 |
| 押して不正解（1着） | −5点 |
| 押して正解（2着） | +5点 |
| 押して不正解（2着） | −3点 |
| 押さずに正解 | +5点 |
| 押さずに不正解 | 0点 |

**3着以降のルールを増やしたい場合**は、「得点ルール設定」カードの
「順位を指定してルールを追加」に着順（例: `3`）を入力して追加すると、
「押して3着」の正解/不正解ルールが新しく追加され、回答者タイルにもボタンとして
すぐに反映されます。何着まででも同様に追加できます。

「全員のスコアを0にリセット」で、大会中いつでも全員のスコアを初期化できます
（問題ごとの「次の問題へ」操作ではスコアはリセットされず、累計されます）。

スコアは判定者画面・投影画面（回答者タイル上）・回答者自身の画面（右上）の
それぞれにリアルタイムで表示されます。得点ルールだけでは表現しきれない状況が
あれば、各タイル下部の「±点数」欄からいつでも手動で加減点できます（5d参照）。

### 7a. 投影画面での早押し演出（点滅・点灯）

早押し機が押されると、判定者画面の「投影画面での早押し演出」カードで設定した
内容にしたがって、投影画面上の**該当者のタイル全体の枠**が光ります（テキストの
通知は表示されません。枠の点滅・点灯だけで誰が押したか伝える仕様です）。

- **1着**: 初期設定は「点滅させる」
- **2着以降**: 初期設定は「点灯させる（点滅しない）」

それぞれ「点滅させる」「点灯させる（点滅しない）」「何もしない」から選べ、
選択するとその場で投影画面に反映されます。次の問題に進む（早押しをリセットする）と
演出は自動的に消えます。

## 8. Arduino早押し機の接続（任意機能）

**早押し機能は使わなくてもアプリは通常どおり動作します。** 早押し機を持っていない、
あるいは会場の事情で接続できない参加者がいても、その人・その部屋はボードへの
手書き解答だけで進行できます。全員で使う必要はなく、一部の参加者だけが早押し機を
使う運用でも問題ありません（未割当のボタンや、ボタン番号を登録していない参加者は
単に早押し判定の対象外になるだけです）。

### 8.1 対応している早押し機

以下の2種類に対応しています。どちらもボーレート9600・改行区切りのテキストを
送るだけの単純な仕組みなので、他の自作マイコンでも同じ形式に合わせれば動きます。

**① RP2040マイコンボードキット早押し機（10〜12端子早押し機）**

市販のキットで組み立てた早押し機です。`arduino/rp2040_10button_kit/hayaoshi_serial.ino`
がそのファームウェアで、**改造・書き換えの必要なくそのまま使えます**。ボタンを押すと

```
ButtonRank<着順>:<ボタン番号>
```

という形式（例: 3番のボタンが1着なら `ButtonRank1:3`）でシリアル送信されます。
サイト側はこの形式を自動で認識します。ボタン番号は1〜10（キットの端子数に依存）です。

**② 自作の簡易早押し機（参考実装）**

`arduino/buzzer_sketch/buzzer_sketch.ino` は、市販キットが無い場合に自分で組める
最小構成のサンプルです（Arduino Uno等＋ボタン数個＋ジャンパー線のみ）。

- 各ボタンの片方をデジタルピン(既定では2〜9番、最大8人分)、もう片方をGNDへ接続
  （プルアップ抵抗を内部で使うため追加部品は不要です）
- Arduino IDEでスケッチを書き込み、ボーレート9600のまま使用してください
- 人数やピン配置を変える場合は `BUTTON_PINS` 配列を編集してください

こちらは

```
BUZZ,<ボタン番号>
```

という形式（例: `BUZZ,3`）で送信します。サイト側は①②どちらの形式が届いても
自動で判別するので、特別な切り替え設定は不要です。

### 8.2 ブラウザとの接続（Web Serial API）

サーバー側には何も設定しません。Arduino/RP2040は**投影PCのブラウザ経由**で直接読み取ります。

1. 早押し機をUSBで投影PCに接続
2. 投影PCの**パソコン版Chromeまたは Edge**で `display.html`（プロジェクター表示画面）を開く
3. 画面上部の「接続する」ボタンを押し、表示されるポート選択ダイアログで早押し機を選ぶ
4. 各回答者が入室時に入力した「早押しボタン番号」と、実際に押したボタンの番号が
   一致していれば、押した瞬間に名前が自動表示されます

> Web Serial APIはパソコン版のChrome/Edgeのみ対応です。スマートフォン・タブレットの
> ブラウザ（iPadのSafariなど）では使えません。投影PCには通常のノートPC/デスクトップ
> をご用意ください。

早押し機が用意できない場合は、判定者画面にある「#1 を押す（テスト）」等のボタンで
動作確認ができます。

### 8.3 通信仕様（自作の早押し機を使う場合）

上記の①②以外の自作マイコンを使う場合も、改行区切りで次のいずれかの形式の文字列を
送るだけで動作します。

```
ButtonRank<着順>:<ボタン番号>
BUZZ,<ボタン番号>
```

例: 3番のボタンが押されたら `BUZZ,3\n` を送信。着順情報は付けてもサイト側では
使用しません（サイト側は受信した順番で自動的に着順を判定します）。

## 9. 制限事項・注意点

- 状態はすべてサーバーのメモリ上に保持されます。**サーバーを再起動（無料プランの
  スリープ復帰を含む）すると部屋やこれまでの回答はすべて消えます。** 大会本番中は
  再起動しないよう注意してください。
- パスワードは簡易的な合言葉程度のものです。厳密なアクセス制御が必要な場合は
  部屋名・パスワードを推測しにくいものにしてください。
- Arduinoとの接続は投影PC1台・1ブラウザタブに限られます（同時に複数の早押し機を
  使う運用には対応していません）。
- 回答画像はサーバー上のメモリに保持されるのみで、ファイルへの自動保存機能は
  ありません。記録を残したい場合は投影画面や判定者画面をスクリーンショットして
  ください。
